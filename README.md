# Chanel Vs Motoboy

Jogo de desvio em canvas vertical. A Chanel se move na horizontal por três fases, acumula pontos até 100 e evita os motoboys. O jogo tem som de latido, controles na tela e um vídeo na tela de vitória.

## Stack

- HTML, CSS e JavaScript
- Canvas 2D
- Capacitor 8, com projeto Android em `android/`
- Identificador do app: `com.chanel.motoboy`

## Como abrir

No navegador, abra `www/index.html`.

Para o projeto Android, use o Capacitor a partir da raiz, com `www/` como diretório web.
